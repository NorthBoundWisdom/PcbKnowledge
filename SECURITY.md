# Security policy

## Supported product boundary

The current PcbKnowledge MVP is a local Git-native editor for trusted internal contributors. It listens
only on `127.0.0.1`, has no account system, accepts no remote clients and has no shared database or object
store. Do not expose its port to a LAN, VPN, container bridge or the internet.

Local operating-system file permissions and Git repository permissions are the access boundary. Git
author identity and commit history provide practical attribution, but are not cryptographic identity or
non-repudiation. A future shared deployment requires a new threat model and authentication ADR.

## Non-negotiable controls

- Invalid or missing schema, source, revision, license, evidence digest or review state fails closed.
- PDF originals are checked from actual bytes, content-addressed and never silently overwritten.
- Committed approved records cannot be rewritten or deleted; corrections use a superseding record.
- PDF/text content is untrusted data and cannot grant tools, change prompts or relax review policy.
- The GUI rejects non-loopback Host/Origin mutation, requires CSRF tokens and uses optimistic revision
  checks.
- Neither GUI nor Agent CLI stages, commits or pushes Git changes.
- The Agent CLI has no approve/reject operation.
- No credentials are required or generated by the current runtime.

## Recovery

Git history protects committed data from ordinary editing mistakes. Review `git diff` before every commit
and push accepted commits to a separately stored remote. Uncommitted records and PDFs exist only in the
current clone; they need their own workstation backup until committed and pushed.

Package ZIPs are validated snapshots, not a replacement for Git history. Verify their SHA-256 sidecar
before transfer.

## Reporting a vulnerability

Use the repository's private GitHub Security Advisory channel. If unavailable, contact the owner through
an established private channel without posting exploit details publicly. Include the affected revision,
local/remote assumptions, reproduction steps and impact. Do not access material you do not own.

Only current `main` is supported during pre-release development.
